# KINOSERA

A cinematic, mobile-first discovery interface for films and television.

## Current experience
- Responsive editorial-style homepage and title catalogue
- Search by title, type, and genre
- Filters for films, series, and selected genres
- Title detail dialogs
- Personal watchlist saved in the browser's local storage
- No build step or API key required

## Run locally
Open `index.html` in a browser, or serve this directory with any static file server.

## Deployment
This is a static HTML/CSS/JavaScript site. For Cloudflare Pages, use the repository root as the build output directory and leave the build command blank. Cloudflare's Git integration can automatically deploy pushes to the configured production branch.

## Catalogue note
The initial titles are a small demonstration catalogue. KINOSERA is an independent discovery interface, not a streaming service, and does not host or provide copyrighted film streams. A future catalogue integration can use a licensed metadata provider and official trailer links.
